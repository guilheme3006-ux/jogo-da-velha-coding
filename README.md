# Jogo da Velha - Trabalho de Coding

## 1. Objetivo
Desenvolver um jogo da velha em Python, executado no terminal, utilizando matrizes, estruturas de repetição e condições.

## 2. Regras do jogo
- O jogo é disputado por dois jogadores.
- O jogador X começa a partida.
- Os jogadores alternam suas jogadas.
- Cada jogador escolhe uma linha e uma coluna para jogar.
- Vence quem completar uma linha, coluna ou diagonal com seu símbolo.
- Se todas as casas forem preenchidas sem vencedor, ocorre empate.
- Não é permitido jogar em uma casa já ocupada.

## 3. Como executar
1. Ter o Python 3 instalado.
2. Baixar ou clonar este repositório.
3. Abrir o terminal na pasta do projeto.
4. Executar o comando:

   `python jogo_da_velha.py`

## 4. Desafio de lógica
**Desafio escolhido:** estatísticas das partidas.

O jogo deverá contabilizar as vitórias de cada jogador e os empates durante a sessão.
